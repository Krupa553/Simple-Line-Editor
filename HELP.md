# HELP – Simple Line Editor

## Project Description
Simple Line Editor is a command-line text editor developed using C programming.

It allows users to insert, delete, display, save and load text lines.

## Available Commands

### 1. Insert Line
Adds a new line at the specified position.

Example:
- Enter choice: 1
- Enter line number: 1
- Enter text: Hello World

### 2. Delete Line
Deletes a line using its line number.

Example:
- Enter choice: 2
- Enter line number: 1

### 3. Display Document
Displays all lines with their line numbers.

Example:
- Enter choice: 3

### 4. Save File
Saves the document into document.txt.

Example:
- Enter choice: 4

### 5. Load File
Loads the saved document from document.txt.

Example:
- Enter choice: 5

### 6. Exit
Closes the editor.

Example:
- Enter choice: 6

## Compilation
gcc line_editor.c -o line_editor

## Execution
.\line_editor.exe
